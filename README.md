# Hearth

An open-source TV interface ("10-foot UI") for cheap Linux home-theatre PCs. A smart-TV replacement that runs like an appliance: easy to install and keep running, driven by a remote or a phone, local only, secure.

Status: design phase. Each piece of product code starts once nothing in the [roadmap](docs/roadmap.md) grid blocks it and the lead asks. The first spike, a working shell on labwc, has answered its software questions: [results](docs/research/2026-11-22-shell-spike-results.md); what's still open: [assessment](docs/research/2026-11-22-open-questions-assessment.md).
